# TEYZOO SIGNAL BOT

Telegram-бот для аналитических торговых сигналов.

## Возможности

- Telegram-бот на Aiogram 3
- PostgreSQL
- FastAPI
- Render Web Service
- автоматический поиск сигналов
- ручной поиск сигнала
- обычные Forex-пары
- фильтр доступных пар
- экспирация от 1 до 20 минут
- режим «Любое время»
- RSI
- MACD
- EMA
- Bollinger Bands
- Stochastic
- ATR
- система оценки качества
- минимальная уверенность 75%
- история сигналов
- WIN / LOSS
- статистика
- автоматическая рассылка
- заявки на вступление
- одобрение пользователей
- отклонение пользователей
- чёрный список
- снятие пользователя с чёрного списка

## Важное ограничение

Бот не выполняет сделки автоматически.

Он только формирует аналитические сигналы.

## OTC

OTC не считается доступным автоматически.

Пока не подключён реальный источник OTC-котировок, бот не должен выдавать фиктивные OTC-сигналы.

## Переменные Render

Необходимо добавить:

- BOT_TOKEN
- DATABASE_URL
- TWELVE_DATA_API_KEY
- ADMIN_IDS

Пример:

ADMIN_IDS=123456789,987654321
